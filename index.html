What it does

Everything a Trainer Tells You,
Automated

Six real-time capabilities driven by pure trigonometry — no machine learning, no server calls, no subscription.

💪
Bicep Curl Counter

Measures your elbow angle frame-by-frame, counting only full reps from complete extension to full curl.

🏋️
Squat Counter

Tracks knee angle and ensures full depth (below 90°) before counting — no half-rep cheating allowed.

👊
Push-up Counter

Monitors elbow angle and full-body alignment, ensuring chest-to-ground depth and locked-arm top position.

🎙️
Voice Coaching

Speaks rep counts and form corrections aloud using offline text-to-speech — so you can keep eyes on form.

⚠️
Real-Time Form Alerts

Detects elbow drift, hip sag, forward knee travel, and chest lean the instant they happen.

⏱️
Session Timer

Tracks your total workout time on screen so you always know how long you've been grinding.

Form rules

The Exact Rules That
Judge Your Form

Every check is a simple if-else angle threshold. Pure high-school trigonometry, zero black-box magic.

01
💪 Bicep Curl
  • ✅ Elbow angle > 155° → arm fully extended (bottom)
  • ✅ Elbow angle < 45° → full curl counted (top)
  • ⚠️ Elbow drift > 12% frame width → "Keep elbow tucked!"
  • ⚠️ Incomplete extension → "Fully extend your arm!"
02
🏋️ Squat
  • ✅ Knee angle > 160° → standing position
  • ✅ Knee angle < 90° → full squat depth counted
  • ⚠️ Knee past ankle > 7% → "Push hips back!"
  • ⚠️ Back lean < 55° → "Chest up!"
03
👊 Push-up
  • ✅ Elbow angle > 155° → top position (lockout)
  • ✅ Elbow angle < 90° → bottom position counted
  • ⚠️ Body angle < 155° → "Don't sag your hips!"
  • ⚠️ Incomplete lockout → "Lock your arms at the top!"
Installation

Running in
4 Steps

No Docker, no cloud account, no configuration files. Just Python and your webcam.

01
Install Python

Download Python 3.9 or newer from python.org. Make sure to check "Add to PATH" during install.

# verify install
python --version
02
Clone the Repo

Clone from GitHub to your local machine, then navigate into the folder.

git clone https://github.com/
rohanxmudrale28/FITNESS-BUDDY
cd FITNESS-BUDDY
03
Install Dependencies

One command installs MediaPipe, OpenCV, pyttsx3, and NumPy.

pip install -r requirements.txt
04
Run!

Point your webcam, stand back 6–8 feet, and start repping.

python fitness_buddy.py

The angle formula
# Given 3 joint positions A, B, C (pixels)
vector_BA = A - B
vector_BC = C - B
angle = arccos( dot(BA, BC) / (|BA| × |BC|) )
# That's it. Pure high school trigonometry.
